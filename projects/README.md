# Python coursework

These are public portfolio copies of Charlie Acosta's supplied assignments.

- `assignment-1-python-fundamentals.ipynb`: Calculator, shopping cart, Rock-Paper-Scissors, and Fibonacci exercises. This is coursework in progress: some code has syntax errors or incomplete behavior. Open it in Jupyter or another notebook viewer. Saved outputs and notebook metadata were cleared for publication; the exercise source is unchanged.
- `assignment-2-data-manipulation.py`: Collection-processing, matrix, API, text-file, and SQLite exercises. The script requires Python 3 and the third-party Requests package. The API sections need internet access; the news section also prompts for a topic and reads `NEWS_API_KEY` from the environment. It writes `joke.txt` and `news.db` in the working directory and recreates the `news` table when run.

The embedded API credential and original Colab document URL were removed from the public script. Supply your own NewsAPI credential through the environment. Original downloaded files were not modified. The assignments were inspected for the portfolio descriptions, not executed or certified as passing tests.
