# cja69-stack.github.io

Charlie Acosta's personal website, hosted at https://cja69-stack.github.io/.

## Pages

- Home: `index.html`
- About Me: `about.html`
- Projects: `projects.html`
- Skills: `skills.html`
- Contact: `contact.html`

Built with plain HTML, CSS, and JavaScript. No installation or build step is required: open `index.html` in a browser to preview the site. Local assets use relative paths.

Every page includes a Dark mode toggle. The theme initially follows the visitor's system setting; choosing a mode saves that preference in browser storage for future visits. If storage is blocked, the toggle still works for the current page.

## Content to complete

The site includes confirmed details (Charlie's name, interest in soccer, and public GitHub profile). Add personal background, education, and proficiency levels when available. Projects include this portfolio and two supplied Python assignments, with descriptions, illustrated previews, and downloadable public copies in `projects/`. The preview images are illustrations, not execution screenshots. See `projects/README.md` for assignment status and setup notes.

The Contact me bubble on every page prepares an email draft addressed to Cja69@njit.edu. Visitors review and send it in their configured email app. The website does not send or store messages and has no backend.
